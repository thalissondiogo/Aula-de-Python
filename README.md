# Aulas de Python — Fundamentos da Programação

Repositório dedicado aos exercícios e projetos desenvolvidos durante as aulas de Python, com foco nos fundamentos da programação e no desenvolvimento da lógica computacional.

## Conteúdos abordados

- Sintaxe básica e estrutura de programas em Python.
- Declaração e utilização de variáveis.
- Entrada e saída de dados com `input()` e `print()`.
- Tipos de dados e conversão de valores.
- Operações matemáticas básicas.
- Manipulação de strings com métodos como `upper()`, `lower()` e `len()`.
- Formatação e exibição de informações no terminal.

## Objetivo

Consolidar os conhecimentos fundamentais de Python por meio de exercícios práticos, desenvolver o raciocínio lógico e construir uma base sólida para projetos futuros em programação e desenvolvimento de jogos.

## Tecnologias

- Python 3

Este repositório documenta minha evolução técnica e meu aprendizado contínuo na área de desenvolvimento de software.
